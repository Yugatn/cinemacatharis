# Дорожная карта

## Этап 1. Зафиксировать ядро
- [x] Выделить исходную концепцию из «Сюжета Икс».
- [x] Зафиксировать триаду: информационная честность, автономия зрителя, культурное разнообразие.
- [x] Описать принцип кинодополняемости.
- [x] Подготовить повторяемый протокол анализа.

## Этап 2. Проверить метод на произведениях
- [ ] Выбрать 3–5 фильмов с различными жанрами и типами повествования.
- [ ] Подготовить карточки анализа по одному шаблону.
- [ ] Сравнить независимые интерпретации нескольких зрителей.
- [ ] Записать расхождения, а не сводить их к искусственному консенсусу.

## Этап 3. Создать этический аудит
- [ ] Разработать чек-лист для документального изображения уязвимых людей.
- [ ] Разделить фактические утверждения, авторскую позицию и художественный приём.
- [ ] Описать процедуру исправления фактических ошибок и контекстуальных искажений.
- [ ] Проверить риски манипуляции, стигматизации и нарушения приватности.

## Этап 4. Экспериментальные форматы
- [ ] Исследовать сопоставление сцены с исходным звуком и без него.
- [ ] Разработать формат обсуждения после просмотра без обязательного единого вывода.
- [ ] При необходимости создать короткометражные этюды с несколькими вариантами монтажа.
- [ ] Отдельно документировать ограничения каждого эксперимента.

## Этап 5. Публичная версия
- [ ] Подготовить примеры анализа с прозрачными источниками.
- [ ] Определить лицензию и правила участия соавторов.
- [ ] Подготовить сайт или каталог материалов, если это потребуется.
- [ ] Публиковать результаты только после проверки воспроизводимости и этических рисков.

## Критерий готовности

Проект готов к следующему этапу, когда другой человек может применить метод без устных пояснений, отделить наблюдение от интерпретации и критиковать сам метод без исключения из обсуждения.
