# Синема Катарсис

**Синема Катарсис** — независимый исследовательско-творческий проект на пересечении кинематографа, психологии восприятия, философии субъекта и этики изображения.

Главный вопрос проекта:

> Можно ли показать переживание другого, не присваивая его?

Кино не является самим событием. Изображение отбирает, связывает и интерпретирует материал; монтаж, звук, музыка, текст, культурный контекст и биография зрителя совместно формируют переживание. Поэтому проект исследует не только то, что показывает фильм, но и то, **как фильм меняет модель происходящего в сознании зрителя**.

## Принципы

- **Свобода интерпретации.** Зрителю не навязывается единственно допустимый вывод.
- **Информационная честность.** Художественная интерпретация не выдаётся за доказанный факт.
- **Автономия субъекта.** Эмоциональное воздействие не должно лишать зрителя права на собственную позицию.
- **Множественность контекстов.** Фильм можно рассматривать психологически, политически, этически, эстетически и философски.
- **Дополняемость.** Изображение, звук, монтаж, текст, память и позиция зрителя взаимодействуют и могут приводить к разным моделям одного произведения.
- **Отсутствие монополии.** Проект не должен становиться единственным источником культурной интерпретации.
- **Уважение к Другому субъекту.** Персонаж, автор и зритель не сводятся к одной интерпретации.

## Статус

Проект находится в стадии формирования концепции и исследовательского метода. Положения о воздействии кино на зрителя являются вопросами для анализа, а не универсальными научными выводами. Конкретные утверждения о психологии, медиаэффектах и поведении следует проверять по источникам и эмпирическим данным.

## Практическое аналитическое ядро (экспериментальная ветка)

Добавлен [Python-модуль](src/cinema_catharsis/metrics.py) для расчёта уникальной длительности экранных предъявлений с учётом пересекающихся интервалов, а также доверительного интервала Уилсона для бинарных ответов в исследованиях. Подробности, формулы и ограничения — в [RESEARCH_ENGINE.md](docs/RESEARCH_ENGINE.md). [Автоматические тесты](tests/test_metrics.py) проверяют перекрытия, дробную частоту кадров и входные параметры.

**Кому полезно:** исследователям медиа, преподавателям медиаграмотности, режиссёрам и монтажёрам, специалистам по этике изображения. Можно измерять, сколько времени в фильме показываются алкоголь, табак, насилие или просоциальные действия, но нельзя выводить из этого прямое изменение поведения зрителей.

**Запуск (Python 3.10+, без зависимостей):** `PYTHONPATH=src python -m unittest discover -s tests`.

**План внедрения:** независимая разметка нескольких фильмов; оценка согласия аннотаторов; открытые отчёты; добровольные рандомизированные исследования вариантов звука/монтажа с этическим одобрением; локальный интерфейс и интеграция с MyPro. Это исследовательский прототип, не автоматический детектор и не клиническая система.


## Pre-upload API для видеохостингов (прототип v0.2)

[Руководство по интеграции](docs/INTEGRATION.md) · [Пример входных данных](examples/preupload.json) · [Модуль правил](src/cinema_catharsis/policy.py) · [Локальный HTTP API](src/cinema_catharsis/server.py)

Перед публикацией платформа может передать **уже размеченные** временные эпизоды, контекст и доказательства в Cinema Catharsis. Ответ содержит отдельные решения по публикации и монетизации, объяснения, таймкоды и возможность апелляции. Пример политики исключает из монетизации подтверждённую коммерческую пропаганду алкоголя, табака и никотина, но не наказывает за документальное, критическое или художественное изображение само по себе.

**Важно:** модуль пока не распознаёт содержимое видеофайла автоматически. Нужны внешние детекторы или ручная разметка. Демонстрационный API работает только локально и не предназначен для публичного развёртывания без защиты. Тесты и исследовательская валидация необходимы до реального применения ограничений.


## Локальная предварительная проверка видео — v0.3

Теперь доступен инструмент анализа **технических метаданных реального видеофайла** (нужен установленный FFmpeg/ffprobe):

```bash
PYTHONPATH=src python -m cinema_catharsis.preflight /путь/к/видео.mp4
PYTHONPATH=src python -m cinema_catharsis.preflight /путь/к/видео.mp4 --annotations examples/preupload.json
```

Первая команда покажет длительность, размер и кодеки, **но не сделает выводов о смысле видео**. Вторая дополнительно применит объяснимые правила к переданной разметке. При отсутствии разметки статус монетизации — `not_assessed`, а не «одобрено». Добавлены `pyproject.toml` для установки как Python-пакета и GitHub Actions для проверки тестов на Python 3.10/3.12/3.13. Реальное автоматическое распознавание сцен, речи и контекста пока остаётся следующим этапом.


## Режим Live Capture / Accelerated Scan (экспериментальный)

Добавлен [браузерный захват экрана](web/capture.html): пользователь выбирает вкладку/окно/экран, запускает фильм и получает снимки кадров с отметками времени захвата, JSON-манифест и, при поддержке браузера, запись звука. [Ограничения и архитектура](docs/LIVE_CAPTURE.md). Захват локальный; **машинное зрение и распознавание речи пока не подключены**. При ×10 короткие эпизоды могут быть пропущены; метки относятся ко времени захвата, а не к таймкоду фильма. Экспорт — отдельные файлы, не ZIP. Запуск через localhost/HTTPS в браузере с поддержкой захвата экрана.


## Локальный ИИ-анализ захваченных кадров и речи — v0.4

[Инструкция](docs/AI_SCAN.md). Подключены **опциональные** модели CLIP для поиска визуальных кандидатов (алкоголь, табак, вейпинг) и Faster-Whisper для транскрипции захваченного аудио. После экспорта из [Live Capture](web/capture.html) можно установить пакет с опциями `pip install -e '.[vision,speech]'` и запустить `cinema-catharsis-scan capture_manifest.json --vision --audio captured_audio.webm --output report.json`. Без моделей команда формирует отчёт о доступных данных. Детекции — только гипотезы для проверки человеком, не доказательства пропаганды или основание для автоматического запрета монетизации. При ускорении ×10 возможны пропуски сцен и ошибки распознавания речи. Точность ещё не валидирована.


## Экспорт отчётов: Excel, Google Таблицы, Google Документы — v0.5

После создания JSON-отчёта запустите `cinema-catharsis-export report.json --output-dir exported`. Будут сформированы **Excel XLSX** (4 листа: Summary, Findings, Transcript, Limitations), четыре CSV для импорта в **Google Таблицы** и HTML-отчёт для копирования или импорта в **Google Документы**. Данные остаются локально; автоматической загрузки в Google Drive пока нет — для неё требуется отдельная авторизация Google OAuth. [Инструкция по экспорту](docs/EXPORTS.md).


## Браузерный просмотр отчёта — v0.6

Добавлен [просмотрщик отчётов](web/report.html) с таблицами обнаруженных признаков и расшифровки речи. Можно выбрать JSON-файл, посмотреть выводы, сохранить CSV для Google Таблиц и HTML для Google Документов без командной строки и без передачи данных на сервер. [Инструкция](docs/BROWSER_REPORT.md). Сам запуск моделей из браузера пока не реализован.


## Состав контента с контролем полноты анализа — v0.7

Добавлен [модуль измерения состава](src/cinema_catharsis/composition.py) и [математическое описание](docs/CONTENT_COMPOSITION.md). Он считает уникальную продолжительность каждой категории без удвоения перекрывающихся интервалов, долю обследованного времени и диапазон возможной доли категории при неполном покрытии. Сцены могут иметь несколько категорий одновременно. Для альтернативной диаграммы, суммирующейся до 100%, предусмотрен явно заданный приоритет категорий. Важно: интервалы должны относиться к **исходной временной шкале фильма**, а не ко времени захвата экрана; выборочные кадры не считаются непрерывным покрытием. Результаты не являются оценкой воздействия на зрителя.


## Исходные таймкоды и измерение точности — v0.8

Добавлен [выборочный анализ кадров по исходным таймкодам](src/cinema_catharsis/media_timeline.py) с помощью FFmpeg (модуль `sample_source_video`) и [статистическая оценка качества детектора](src/cinema_catharsis/calibration.py) (`calibration_report`: precision, recall, F1, Brier, ECE). [Методология и ограничения](docs/VALIDATION.md). Извлечённые кадры не означают непрерывного просмотра всего фильма. Для проверки точности нужны независимые размеченные видеоданные; результаты CLIP не являются автоматически откалиброванными вероятностями.


## Cinema Catharsis Family — мобильный навигатор v0.9

Добавлен [адаптивный семейный интерфейс](web/family.html): родители формируют локальную подборку HTTPS-ссылок, интерфейс адаптирован к смартфонам, не требует аккаунта и не отправляет историю просмотров на сервер. [Концепция и ограничения](docs/MOBILE_FAMILY.md). Это **не полноценный безопасный браузер**: нет блокировки переходов внутри сторонних сайтов, защиты настроек PIN-кодом или системного родительского контроля. Для реальной защиты детей требуются отдельные нативные механизмы и аудит безопасности.


## Cinema Catharsis Transparency Browser — v0.10

Цель — информировать о **составе контента без цензуры**. Добавлены [адаптивный веб-анализатор текста](web/composition.html) и [прототип расширения Chromium](extension/manifest.json) для добровольного локального анализа текста активной вкладки. Сейчас анализируются **только словарные совпадения** (не семантика, не видео, не изображения и не степень психологического воздействия). Расширение не блокирует страницы, не отправляет историю просмотров и не требует доступа ко всем сайтам. [Архитектура для ПК, Android и iOS](docs/TRANSPARENCY_BROWSER.md). Это ещё не самостоятельный защищённый браузер; расширение рассчитано на настольный Chromium, а веб-интерфейс — на разные размеры экранов.
